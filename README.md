# 🧙‍♂️ Harry Potter Invisibility Cloak (OpenCV)
This project recreate the famous Invisibility Cloak effect from Harry Potter using Python and OpenCV. The idea is to allow the program to detect a specific color(in my case, blue) in a video stream and replace that region with the background, creating the Invisibility Cloak effect. 

## 🧰 Requirements
- Python 3.x
- OpenCV
- NumPy

You can install the required packages using pip:
```bash
pip install opencv-python numpy
```
